# 문화재 사진 확보 가이드

## 원칙
1. 사진마다 **이용 조건을 확인**하고, `src/data/questions/imageCredits.ts`에 출처·조건을 적습니다(정답이 드러나지 않게 문화재 이름은 빼고).
2. 이용 조건이 불분명하면 쓰지 않습니다. 인터넷 검색 결과 이미지를 그대로 가져오지 않습니다.
3. 파일은 `public/images/culture/`에 jpg로 넣고, `npm run check:images`로 빠진 파일과 출처를 점검합니다.

## 공공누리 유형 (한국 공공기관 자료)
| 유형 | 조건 |
|---|---|
| 0 | 출처 표시 없이 자유 이용 |
| 1 | 출처 표시, 상업·비상업 이용 가능, 변경 가능 |
| 2 | 출처 표시, **상업적 이용 금지**, 변경 가능 |
| 3 | 출처 표시, 상업·비상업 이용 가능, **변경 금지** |
| 4 | 출처 표시, **상업적 이용 금지, 변경 금지** |

- 변경 금지에는 형식 변경이나 2차적 저작물 작성도 포함된다고 안내됩니다. 자르기·크기 조정이 필요하면 0·1·2유형을 우선 고르세요.
- 서비스를 유료로 운영하거나 광고를 붙일 계획이면 2·4유형은 피하세요.

## 찾아볼 곳
- 국가유산청 국가유산포털(heritage.go.kr): 박물관 소장품, 국가유산디지털서비스, 국가유산청 사진관
- 국립중앙박물관 누리집: 자료마다 공공누리 표시를 확인
- 위키미디어 커먼즈: 파일마다 라이선스가 다르고(CC BY-SA 등) 출처·저작자 표시 의무가 있으니 파일 페이지에서 확인
- 직접 촬영: 박물관·유적지의 촬영 규정을 확인

## 주의할 문화재
- 몽유도원도는 해외 소장품이라 국내 공공기관 사진이 없을 수 있습니다. 이용 허락을 받을 수 없으면 해당 문제를 삭제하거나 다른 그림으로 교체하세요.
- 이불병좌상(발해)도 공개된 사진이 제한적일 수 있어 확인이 필요합니다.
- 수량이 많은 문화재(고인돌, 척화비)는 소장처가 여러 곳이라 이용 조건이 좋은 사진을 고르세요.
